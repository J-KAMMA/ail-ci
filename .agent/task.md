# ffre1: a regex benchmark: AIL's `re` against CPython's `re` and Rust's `regex` crate, same patterns, same text

Time budget: 60 minutes. Commit and push after each sub-step. Follow `C:\Users\bluec\ail-work\agent-brief-rules.md`
(no regressions, CI first, memory cap).

**Number this moves:** per workload, AIL wall time and instruction count against CPython and Rust `regex`. Today
there is no number for `re` speed. The target is a filled table for 8 workloads, with identical match output on all
three, and the slowest workload named for ffre2.

Base: `origin/integ`. Files you may create or edit, and no others:
- `lab/regex/gen_text.py` (new: a seeded generator of a 20 MB log-like ASCII text and a 2 MB mixed non-ASCII text)
- `lab/regex/w*.py` (8 new workloads, plain Python), `lab/regex/rust/` (new: one binary per workload or one binary
  with a workload argument, same algorithm)
- `lab/regex/run.py` (new: builds, runs, checks the output digest, measures median of 5 and icount),
  `lab/regex/RESULTS.md`

Workloads: a literal search count; a case-insensitive word alternation (`error|warn|fatal`); `\d+` extraction with
`int()` sums (probe a run of 25 digits: CPython prints the exact sum, AIL must stop loudly or print the same);
an IPv4 pattern with groups; a log line parse with 5 named groups; `re.sub` with a group template; `re.split` on
`\s*,\s*`; `fullmatch` validation of a million short strings. Each prints a digest (counts and a hash), never timing.

## Appendix B: repository facts

- Build: `python3 -B AIL_CURRENT/ail_chatgpt.py compile SRC -o OUT [--strict] [--debug-dir DIR]`. `DIR/program.c` is
  the generated C. `--strict` means the typed path or a refusal. `-o` must not exist yet. A fallback to the general
  path prints `note: ... built on the general path ...` on stderr.
- AIL is Python syntax plus optional annotations. Ints are int64, and overflow stops loudly. Release builds use
  gcc -O2.
- Library policy: a small spec library is written in AIL (`AIL_CURRENT/stdlib/*.py`, found by `ail_modules.py`
  `BUNDLED_DIR`); TLS, signatures and SQLite go through proven native libraries.
- Runtime-backed modules follow `AIL_CURRENT/python/pkg-v12/proclib.py` (stage G8, subprocess): a tree-to-tree pass
  plus a C core header (`ailproc_core.h`), wired by two lines in `filelib.py` (`PRIMS.update(...)` near line 66 and
  `rewrite_tree(...)` near line 152). A program that does not import the module must produce byte-identical C.
- CPython 3.12 is the oracle: compare stdout and the exit status, and stderr where a task says so.
- Speed claims: instruction counts with `tools/icount.c`, output unchanged.
