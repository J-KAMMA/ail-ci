# onelang s5: Python twins of every `language_examples` source, kept in sync by a test

Time budget: 80 minutes. Commit and push after each sub-step.

**Number this moves:** every brace `.ail` in `AIL_CURRENT/language_examples` (262 files) gets a converted `.py` twin
beside it; the 6 Python-syntax `.ail` files there get a `.py` copy. A test fails when a twin is stale. The corpus
report of s3 stays as good (same counts).

Base: `origin/integ` after onelang s4 merged.

## Sub-steps

1. `tools/ail2py.py --twins DIR`: for each `X.ail` in DIR: brace -> converted `X.py`; Python syntax -> copy as `X.py`.
   If `X.py` already exists and is not a twin (11 `row_*.py`/`ordinary_join_price.py` tools exist; check names), stop
   for that file and list it. Each twin starts with the line `# generated by tools/ail2py.py from X.ail; edit the .ail
   until onelang s16` . Commit, push, open the PR.
2. Check nothing changed for existing programs: Python programs that import a module from this directory now find
   `m.py` beside `m.ail`. Run `tools/par_check.py -j 2` on every test module that reads `language_examples` (Appendix C)
   and on `test_ail_ail2py`. Commit, push.
3. `AIL_CURRENT/test_ail_onelang_twins.py`: for each twin, re-convert the `.ail` and compare text (fast, no builds); and
   build 10 fixed twins (entries that are `identical` in s3's report, including two multi-module ones) both ways and
   compare C (`identical`/`identical-renamed`). Register it, `tools/update_manifest.py`, `--check`. Commit, push.

## Done-check

`python3 AIL_CURRENT/test_ail_onelang_twins.py` passes; the twin count equals the `.ail` count of the directory; the
listed modules pass; all 20 shards pass.

## Stop rule

Stop if: a `.py` twin changes what an existing test builds (module lookup picks the twin and the result changes); a name
clash with an existing `.py`; a compiler change outside the files named here would be needed; any compare-lab `program.c` changes; any listed test module fails for a reason the base did not have; or 80 minutes pass. Push what is green and report. Do not touch `.github/workflows`.
