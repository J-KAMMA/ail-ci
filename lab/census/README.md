# lab/census

LLM-written Python programs (Claude Haiku, 2026-10-19) used to find what AIL does not build yet.
`programs/gdev` are self-contained programs in 26 areas, and `programs/dev` are solutions to the
lab/corpus task prompts. A held-out half of each set stays private for the final measurement.

The census-lab workflow sorts every program into: built on the typed path, built on the general
path, or refused by both, and prints the counts.
