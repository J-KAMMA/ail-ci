# typeshed1: vendored stubs and the signature table

Generated by `tools/typeshed_reach.py` against `AIL_CURRENT/python/pkg-v12/stubsigs_table.py` (typeshed
commit `bd58d637aaa73ec8d7a9ec5e2ad8809a5dd86272`, CPython 3.12 on Linux).

## Before typeshed2

No compiler file imports `stubsigs` yet, so the generated C and the compile time of every program are unchanged.
The counter counts calls whose callee resolves to a vendored module: `mod.f(...)`, `from mod import f; f(...)`,
`import mod as alias; alias.f(...)`, class constructors (`mod.Class(...)`), and methods of a returned object
(`re.compile(...).match`) as total but unknown. A class's constructor signature comes from `__init__` when the stub
has one, else from `__new__` (typeshed uses `__new__` for immutable classes such as `datetime.date`, `Decimal`,
`Fraction`); between overloads the converter keeps the one with the most parameters, so `datetime.date(year, month,
day)` and `deque(iterable, maxlen=...)` carry their parameters rather than an empty tuple. A class that defines
neither inherits the constructor of its first resolvable base (`builtins.ValueError` gets
`BaseException.__init__(self, *args)`), so only classes with no constructor anywhere in the vendored stubs or an
explicit no-argument constructor keep `()`. A `@property` getter/setter pair is an attribute: its parameters are
empty and its ret is `obj` when the getter and setter disagree (`sqlite3.Connection.autocommit`), so a setter
returning `None` never masquerades as the getter's ret. An overload set whose members all agree on the return type
gets that ret with empty flags; `overload` flags only a set that disagrees (`obj`).

## typeshed2: stub-typed scalar calls on the general path

`stubcalls.py` answers `unified._etype` for an `ast.Call` whose callee resolves to a vendored stdlib entry
with an `int`/`float`/`bool` return and no overload disagreement. The emitter runs the general path's own call and
unboxes the result. For lowered `_ail_math_*` helpers the qualname maps back to `math.*`; a typed `pfu_` clone is
called with native arguments, and only a clone that already returns the scalar skips the tag check. Any other tag
stops with `AIL stub call <name>: stub says <type>` (exit 2), so a stub can never return a value of another type.
`AIL_STUBCALLS=0` turns the feature off. Exact-int functions and `fp.exact` keep `int` results boxed.

The affected set is the 87 programs in `lab/census/programs` and `lab/stdlib` with an `int`/`float`/`bool` scalar
site (`tools/typeshed_reach.py --list`). All builds below use `AIL_SERVER=0`, a fresh `AIL_SERVER_DIR`,
`AIL_NO_CACHE=1` and `ulimit -v 1500000`.

differs only after the change, in either build.
