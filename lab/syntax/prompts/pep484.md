SYNTAX NOTES (AIL, Python style with PEP 484 annotations):
- This is ordinary Python syntax: indentation blocks, `def`, `:` after headers, no semicolons, `#` comments, `and`, `or`, `not`, `elif`.
- Annotate every parameter and return type: `def name(a: int, b: str) -> int:`; use `-> None` for no result. Annotate variables when the type is not obvious: `xs: list[int] = []`, `n: int = 0`. A name keeps one type for the whole function.
- Top level holds only `import sys`, `from dataclasses import dataclass`, constants, dataclasses and functions. No global variables, no nested functions, no other classes. Tuples work: `return a, b`, `q, r = f(x)`, `list[tuple[int, int]]`, tuple dict keys.
- Types: `int` (64-bit), `float`, `str`, `bool`, `list[T]`, `dict[str, T]` / `dict[int, T]`, `set[int]`. T is int, float, str or bool for containers.
- Entry point: `def main() -> int:` that ends with `return 0`, and end the file with `if __name__ == "__main__":` / `    main()` (a main that is never called is refused).
- Records: `@dataclass` followed by `class P:` with annotated fields (`x: int`, `name: str`), build with `P(1, "a")`. Methods are allowed inside the class and take `self`. Dataclass instances are shared references and may be changed through a function parameter. Flat lists, dicts and sets passed as parameters are read-only: return a new one or keep it in a dataclass field.
- Input: `for line in sys.stdin:` yields lines with the trailing newline kept; use `line.strip()`, `line.split()`, `int(s)`. `print(a, b)` joins with spaces; `print(xs)` of a list is not allowed, use `" ".join(list_of_str)`. f-strings work.
- Strings: `len`, indexing `s[i]` gives a str, slices, `lower`, `upper`, `isalpha`, `isdigit`, `isalnum`, `join`, `split`, `strip`, `replace`. `+` never mixes str and numbers: use `str(n)`. There is no `ord`/`chr` conversion between a str and a number: to shift letters, look a letter up with `ABC.find(ch)` in a str constant and index it again with `ABC[i]`.
- Lists: `append`, `pop`, `sort()`, `sorted(xs)`, `xs.sort(key=lambda i: (-w[i], i))` (lambdas work as keys and as values that capture nothing that changes later). Dicts: `d[k]`, `k in d`, `d.get(k, default)`, `for k in d`, `for k, v in d.items()`, `sorted(d)`. `zip`, `enumerate`, `map`, `filter` work. Libraries: `math`, `re`, `collections` (Counter, defaultdict, deque, OrderedDict), `itertools`, `functools`, `heapq`, `bisect`, `random` (after `random.seed(n)`), `json` (into a declared type).
- Errors: `try: ... except ValueError as e: ...`; name the exception kinds (ValueError, KeyError, IndexError, ZeroDivisionError); no bare `except`. `raise ValueError("message")`. `int("abc")` raises ValueError.
- Example:
```
import sys
from dataclasses import dataclass

@dataclass
class Acc:
    total: int
    names: list[str]

def add(acc: Acc, name: str, v: int) -> None:
    acc.names.append(name)
    acc.total += v

def main() -> int:
    acc = Acc(0, [])
    for line in sys.stdin:
        f = line.split()
        try:
            add(acc, f[0], int(f[1]))
        except ValueError:
            print("bad", f[0])
    print(acc.total, len(acc.names))
    return 0

if __name__ == "__main__":
    main()
```
