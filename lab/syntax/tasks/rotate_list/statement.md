# rotate_list

Category: lists

Read standard input, write standard output, exit with status 0.

The first line holds an integer k >= 0. The second line holds a non-empty list of integers separated by spaces. Rotate the list right by k positions (the last k elements move to the front; k may exceed the length) and print it, separated by single spaces.

Example: `2` then `1 2 3 4 5` gives `4 5 1 2 3`.
