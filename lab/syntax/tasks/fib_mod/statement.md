# fib_mod

Category: numeric loops

Read standard input, write standard output, exit with status 0.

Each input line holds two integers n and m (0 <= n <= 100000, 1 <= m <= 1000000007), separated by a space. Print F(n) mod m, where F(0)=0, F(1)=1. Intermediate sums must not overflow a 64-bit integer.

Example: input `10 1000` gives `55`.
